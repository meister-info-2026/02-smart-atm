# 작품 전시회 시연 매뉴얼 — 스마트 금융 보안 ATM

> **전시회 당일에는 이 문서 하나만 본다.**
> 관람객 앞에서는 자동 테스트를 돌리지 않는다. 처음부터 끝까지 **손으로 조작하는
> 시연**으로 100% 진행한다. 자동 테스트는 시연 전 "장비가 멀쩡한가"를 확인하는
> 용도로만 쓴다(2-2절).
>
> | 이럴 때는 | 이 문서를 본다 |
> |---|---|
> | 전시회 당일 시연 | **이 문서 (04)** |
> | 설치·테스트·코드 수정 | `docs/01_윈도우-개발-핸드북.md` |
> | 실행 절차 전반 | `docs/02_스마트금융보안ATM-실행-가이드.md` |

**1차 완성 기준: 윈도우 PC 1대에서 100% 진행한다.** 라즈베리파이 5는 2차 확장이며,
전시회 시연에 필요하지 않다. ATM 역할은 PC에서 도는 프로그램과 브라우저 화면이 대신한다.

---

## 0. 이 시연으로 무엇을 보여주는가 (30초 요약)

> "보이스피싱 문자를 받은 어르신이 ATM 앞에 섰을 때, **ATM이 스스로 현금 출금을
> 막아 주는** 시스템입니다."

관람객이 반드시 봐야 하는 **핵심 장면 하나**는 이것이다.

> **위험 문자로 만든 QR을 보여준 뒤 50만 원 버튼을 눌러도, 현금이 나오지 않는다.**

나머지 장면은 이 한 장면을 설득하기 위한 앞뒤 맥락이다. 시간이 없으면 장면 2·4·6만
보여줘도 시연은 성립한다.

## 1. 준비물

| 준비물 | 수량 | 비고 |
|---|---|---|
| 윈도우 노트북 (개발 환경 설치 완료) | 1대 | 이 PC 한 대로 전부 돌아간다 |
| USB 웹캠 또는 노트북 내장캠 | 1개 | QR을 비추는 용도 |
| 휴대폰 | 1대 | QR을 화면에 띄워 웹캠에 보여준다 |
| 외부 모니터 (선택) | 1대 | 있으면 관람객이 훨씬 잘 본다 |
| 인쇄한 이 문서의 7절 요약 | 1장 | 당일 손에 들고 있는다 |
| 비상용 QR 이미지 파일 | 2개 | 2-4절에서 미리 만들어 둔다 |

> 라즈베리파이, 서보모터(MG996R), 브레드보드는 **전시회에 가져가지 않아도 된다.**
> 1차 완성은 PC만으로 완결된다.

## 2. 전날 리허설 (필수 · 30분)

당일 처음 켜 보는 일이 없게 한다. 전날 반드시 아래 세 가지를 마친다.

### 2-1. 전체 흐름을 손으로 1회 완주한다

4절 시연 대본을 처음부터 끝까지 **그대로** 해 본다. 중간에 막히는 곳이 있으면
그 자리에서 6절 사고 대응표를 찾아 해결해 둔다.

### 2-2. 자동 테스트로 "장비가 멀쩡한지" 확인한다

이건 관람객에게 보여주는 것이 아니라, **전날 밤 내 코드가 성한지 확인하는 절차**다.
저장소 루트에서:

```powershell
.\venv\Scripts\Activate.ps1
pytest
```

마지막 줄이 이렇게 나오면 정상이다.

```
53 passed, 1 warning in 1.03s
```

`failed`라는 단어가 보이면 **전시회 준비를 멈추고 먼저 고친다.** 읽는 방법은
`docs/01_윈도우-개발-핸드북.md` 3-1절에 있다.

### 2-3. `.env` 두 값을 눈으로 확인한다

리허설에서 QR을 비췄는데 ATM 화면이 안 바뀌면 십중팔구 여기다.

```powershell
Get-Content pi\.env      | Select-String "BACKEND_URL|DEVICE_API_KEY"
Get-Content backend\.env | Select-String "DEVICE_API_KEY"
```

- `BACKEND_URL` 이 **`http://127.0.0.1:8000`** 인가
- 두 파일의 `DEVICE_API_KEY` 가 **완전히 같은가**

고쳤다면 **창 3을 반드시 껐다 켠다** — `.env`는 시작할 때 한 번만 읽는다.

### 2-4. 비상용 QR 이미지를 미리 만들어 둔다

당일 백엔드가 안 뜨거나 인터넷이 끊겨도 시연을 이어갈 수 있게, QR 이미지 파일을
바탕화면에 저장해 둔다.

```powershell
.\venv\Scripts\Activate.ps1
python -c "import qrcode, json; qrcode.make(json.dumps({'session_id':'VP-000002','risk_level':'DANGER'})).save('danger.png')"
python -c "import qrcode, json; qrcode.make(json.dumps({'session_id':'VP-000001','risk_level':'SAFE'})).save('safe.png')"
```

`danger.png`, `safe.png`를 **휴대폰에도 전송해 둔다.** 휴대폰 사진첩에서 바로 띄워
웹캠에 보여줄 수 있다.

> 이 QR에는 위험 등급이 직접 들어 있어서, 백엔드가 죽어도 ATM이 **로컬 판단으로**
> 차단까지는 보여줄 수 있다. 다만 콜센터 해제(장면 6)는 백엔드가 살아 있어야 한다.

## 3. 당일 세팅 (시연 30분 전 · 10분 소요)

### 3-1. PowerShell 창 3개를 순서대로 띄운다

**순서를 지킨다.** 창 1이 먼저 떠 있어야 창 3이 정상 동작한다.

| 창 | 명령 | 이 글자가 보이면 성공 |
|---|---|---|
| **창 1**<br>백엔드 | `cd backend`<br>`..\venv\Scripts\Activate.ps1`<br>`uvicorn main:app --port 8000` | `Uvicorn running on http://127.0.0.1:8000` |
| **창 2**<br>프론트엔드 | `cd frontend`<br>`npm run dev` | `Local: http://localhost:3000` |
| **창 3**<br>ATM 데몬 | `cd pi`<br>`..\venv\Scripts\Activate.ps1`<br>`python main.py` | `카메라 열림 (index=0, backend=dshow)` |

> **창 3의 이 줄이 가장 중요하다.** `카메라 열림`이 안 보이고 `카메라를 열 수 없습니다`가
> 보이면 웹캠 문제다 — 6절 A번 항목으로 간다.

세 창은 시연이 끝날 때까지 **끄지 않는다.** 창 3은 로그가 계속 찍히므로 관람객에게
보여주면 설득력이 올라간다(장면 4에서 활용).

### 3-2. 시연 데이터를 새로 넣는다

전날 시연으로 세션이 지저분해졌을 수 있다. 창 1을 잠깐 끄고:

```powershell
cd backend
python -m db.seed
```

이 출력이 나오면 정상이다.

```
시연 데이터 생성 완료
  사용자 계정   : halmeoni / demo1234
  상담원 계정   : callcenter / demo1234  (role=agent)
  채팅방 3개(정상 문자 1, 보이스피싱 문자 2)와 장치 3개를 등록했습니다.
```

다시 창 1에서 `uvicorn main:app --port 8000`을 켠다.

### 3-3. 화면 3개를 미리 열어 둔다 — **탭 C는 시크릿 창으로**

| 화면 | 어디에 여나 | 주소 | 로그인 계정 | 역할 |
|---|---|---|---|---|
| 탭 A | 일반 창 | `http://localhost:3000/messages` | `halmeoni` / `demo1234` | 어르신 휴대폰 |
| 탭 B | 일반 창 | `http://localhost:3000/atm` | 로그인 불필요 | ATM 화면 |
| 탭 C | **시크릿 창** | `http://localhost:3000/callcenter` | `callcenter` / `demo1234` | 콜센터 상담원 |

> ⚠️ **탭 C는 반드시 시크릿 창(Ctrl+Shift+N)에서 연다.** 로그인 정보는 브라우저 하나에
> 하나만 저장되므로, 일반 창에서 `callcenter`로 로그인하면 탭 A의 `halmeoni` 로그인이
> **덮어써진다.** 시크릿 창은 저장 공간이 분리되어 두 계정을 동시에 유지할 수 있다.
>
> 시크릿 창을 못 쓰는 환경이면 **다른 브라우저**(예: 탭 A·B는 Chrome, 탭 C는 Edge)를
> 써도 된다.

**세 화면 모두 미리 로그인까지 끝내 둔다.** 관람객 앞에서 비밀번호를 치지 않는다.

> 탭 C에 `halmeoni`로 로그인하면 "콜센터 상담원 계정으로 로그인해야 합니다" 안내가
> 뜬다. 버그가 아니라 **의도된 보안 동작**이다(장면 7의 설명 소재로 쓴다).
> 이때는 화면 오른쪽 위 **"계정 바꾸기"** 를 눌러 `callcenter`로 다시 로그인한다.

### 3-4. 화면 배치와 웹캠 위치

- 외부 모니터가 있으면: **모니터에 탭 B(ATM)**, 노트북에 탭 A·C
- 웹캠은 관람객이 서는 쪽이 아니라 **발표자 손이 닿는 곳**에 둔다
- 웹캠과 휴대폰 거리는 **20~30cm**. 휴대폰 화면 밝기는 **최대**로 올린다
- 형광등 반사가 심하면 휴대폰을 살짝 기울인다

### 3-5. 최종 점검 5줄

시연 직전 이 5개만 눈으로 확인한다.

- [ ] 창 1에 `Uvicorn running` 이 있다
- [ ] 창 3에 `카메라 열림` 이 있다
- [ ] 탭 B(`/atm`)에 **"휴대폰 화면의 QR 코드를 카메라에 보여 주세요"** 가 떠 있다
- [ ] 탭 C(`/callcenter`) 우측 상단 배지가 **초록색 "실시간 연결됨"** 이다
- [ ] 탭 C가 **시크릿 창**이고 `callcenter`로 로그인돼 있다 (세션 목록이 보인다)
- [ ] 휴대폰에 `danger.png` 가 열려 있다 (비상용)

## 4. 시연 대본 (7장면 · 약 5분)

각 장면은 **[조작] → [화면에 나타나야 하는 것] → [관람객에게 할 말] → [안 되면]**
순서다. 굵은 글씨는 화면에 실제로 나오는 문구다.

---

### 장면 1. 정상 문자는 아무것도 막지 않는다 (30초)

**[조작]** 탭 A(`/messages`)에서 **`010-2345-6789 (딸)`** 대화방을 고르고,
`엄마, 오늘 오후 3시에 병원 예약이 있습니다. 잊지 마세요.` 문자를 선택해 검사한다.

**[화면에 나타나야 하는 것]**
- 결과 화면에 **"위험 점수 0점 / 100점"**, 등급 **안전**
- 안내: **"위험한 내용이 없습니다. 평소처럼 은행 업무를 보셔도 됩니다."**
- **QR이 나오지 않는다**

**[관람객에게 할 말]**
> "평범한 문자는 시스템이 건드리지 않습니다. 위험한 문자일 때만 개입합니다."

**[안 되면]** 문자 목록이 비어 있으면 → 3-2절 seed를 다시 돌린다.

---

### 장면 2. 보이스피싱 문자를 잡아낸다 (40초)

**[조작]** 탭 A에서 **`02-500-0000 (모르는 번호)`** 대화방을 고르고,
`검찰입니다. 계좌가 범죄에 연루되었습니다...` 문자를 검사한다.

**[화면에 나타나야 하는 것]**
- **"위험 점수 100점 / 100점"**, 등급 **위험**
- **"이렇게 판단했습니다"** 아래 근거 **4개**
  - 기관 사칭 표현 감지
  - 범죄 연루 언급 감지
  - 현금 인출 요구 감지
  - 특정 장소 현금 전달 요구 감지
- **"ATM에서 이 QR을 보여 주세요"** 와 함께 **QR 코드**가 뜬다
- QR 아래에 **`VP-000002`** 같은 세션 번호

**[관람객에게 할 말]**
> "왜 위험한지를 4가지 근거로 설명해 줍니다. 그냥 '위험'이라고만 하면 어르신이
> 납득하기 어렵기 때문입니다. 그리고 이 판정 결과를 **QR 코드**에 담습니다."

**[안 되면]** 점수가 100점이 아니면 → 코드를 고친 것이 원인이다. 시연은 그대로
진행해도 되지만(위험 등급만 맞으면 된다), 끝난 뒤 `pytest`로 확인한다.

---

### 장면 3. ATM이 QR을 읽는다 — **핵심 준비 동작** (30초)

**[조작]** 휴대폰으로 탭 A의 QR을 촬영하거나, 휴대폰에서 같은 결과 화면을 열어
**QR을 웹캠에 20~30cm 거리로 비춘다.**

**[화면에 나타나야 하는 것]**
- 창 3 로그에 **`QR 인식: {"session_id": "VP-000002"}`**
- 탭 B(`/atm`) 화면이 **빨간색**으로 바뀌고 큰 글씨로
  **"보이스피싱 위험이 확인되어 현금 출금을 잠시 멈췄습니다"**
- 그 아래 탐지 근거 4개가 그대로 표시된다

**[관람객에게 할 말]**
> "ATM이 휴대폰 QR을 읽는 순간, 이 사람이 방금 보이스피싱 문자를 받았다는 걸
> 알게 됩니다. 은행 서버를 거치지 않고 **ATM이 스스로** 판단합니다."

**[안 되면]** 5초 안에 안 읽히면 **바로 비상 절차로 넘어간다** — 6절 A번.
관람객 앞에서 웹캠과 씨름하지 않는다.

---

### 장면 4. 돈이 나오지 않는다 — **이 작품의 핵심** (60초)

가장 중요한 장면이다. **천천히, 관람객이 화면을 볼 시간을 주면서** 진행한다.

**[조작]** 탭 B(`/atm`)에서 **`500,000원`** 버튼을 누른다.

**[화면에 나타나야 하는 것]**
- 화면 아래 노란 알림:
  **"현금이 나오지 않습니다. 보이스피싱 위험으로 출금이 멈춰 있습니다."**
- 창 3 로그에 **`출금 차단 (state=WITHDRAW_BLOCKED, session=VP-000002)`**

**[관람객에게 할 말]**
> "버튼은 그대로 눌립니다. 화면도 잠기지 않습니다. 그런데 **돈이 안 나옵니다.**
> 실물 ATM이라면 여기서 현금 배출 장치가 아예 움직이지 않습니다.
> 어르신이 속아서 버튼을 눌러도 피해가 발생하지 않는 겁니다."

> 💡 **연출 팁**: 버튼을 **두세 번 더 눌러 본다.** 매번 같은 안내가 뜨고 창 3에
> `출금 차단` 로그가 쌓이는 것을 보여주면 "정말 막혀 있구나"가 전달된다.

**[안 되면]** 돈이 배출되면(`50,000원을 배출했습니다`) 장면 3의 QR이 제대로 안 읽힌
것이다. 탭 B 하단 **"처음으로"** 를 눌러 초기화하고 장면 3부터 다시 한다.

---

### 장면 5. 사람에게 확인을 요청한다 (30초)

**[조작]** 탭 B에서 **"상담원 확인 요청하기"** 버튼을 누른다.

**[화면에 나타나야 하는 것]**
- 탭 B가 **"상담원이 확인 중입니다. 잠시만 기다려 주세요"** 로 바뀐다
- 탭 C(`/callcenter`)에 방금 세션(`VP-000002`)이 나타난다
- 세션을 클릭하면 **문자 원문과 탐지 근거 4개**가 그대로 보인다

**[관람객에게 할 말]**
> "기계가 완전히 잠가 버리면, 진짜로 돈이 필요한 상황에서 곤란해집니다.
> 그래서 **사람이 최종 확인**하는 단계를 뒀습니다."

---

### 장면 6. 사람이 풀어 줘야만 풀린다 (40초)

**[조작]** 탭 C에서 세션을 고르고 **"정상 거래 — 제한 해제"** 를 누른다.
그다음 탭 B로 돌아가 **3초 정도 기다린다.**

**[화면에 나타나야 하는 것]**
- 탭 B가 초록색으로 바뀌며 **"출금하실 금액을 선택해 주세요"**
- 여기서 **`50,000원`** 을 누르면 **"50,000원을 배출했습니다."**
- 창 3 로그에 **`[MOCK] 현금 배출 동작 (누적 1회)`**

**[관람객에게 할 말]**
> "상담원이 확인해서 풀어 주면, 그때서야 돈이 나옵니다.
> **어르신 본인은 이 제한을 풀 수 없습니다.** 보이스피싱범이 '지금 화면에서
> 해제 누르세요'라고 시켜도 소용이 없게 만든 겁니다."

**[안 되면]** 3초를 기다려도 안 바뀌면 최대 10초까지 기다려 본다(3초 주기로
서버에 물어보는 구조다). 그래도 안 되면 탭 B를 새로고침한다.

> 반대로 **"보이스피싱 — 제한 유지"** 를 누르면 ATM은 계속 막혀 있다.
> 시간이 있으면 이 분기도 함께 보여준다.

### 장면 7. 아무 QR이나 통하지 않는다 (30초 · 선택)

### 수동 QR 투입 (웹캠 없이 시연을 이어가는 법)

**네 번째 PowerShell 창**을 미리 하나 열어 두고, 아래 명령을 **미리 붙여넣어 둔다.**
Enter만 치면 되도록 준비해 두는 것이 핵심이다.

```powershell
# 위험 QR을 넣는다 (장면 3 대체)
Invoke-RestMethod -Uri http://localhost:8100/qr -Method Post `
  -ContentType "application/json" `
  -Body '{"data": "{\"session_id\": \"VP-000002\"}"}'
```

```powershell
# 초기화 (장면 5 대체 / 관람객 교대 시)
Invoke-RestMethod -Uri http://localhost:8100/reset -Method Post
```

> PowerShell에서는 **작은따옴표** 안에 JSON을 넣어야 `\"` 가 그대로 전달된다.
> `curl.exe` 로 하면 따옴표 처리가 까다로워 자주 실패한다.
>
> `VP-000002` 자리에는 장면 2에서 나온 **실제 세션 번호**를 넣어야 한다.
> 번호가 다르면 "등록되지 않은 QR"로 거부된다.
