2. **[필수 01]** [01_윈도우-개발-핸드북.md](./01_윈도우-개발-핸드북.md) ➡️ 1부 설치 및 3-3절(ATM 데몬) 실습.
3. **[필수 03]** [03_데이터-연동-규격.md](./03_데이터-연동-규격.md) 3절 ➡️ 라즈베리파이가 호출할 4개 엔드포인트 모양 확인.
4. **[부록 A]** [부록A_라즈베리파이5-연동-인터페이스-가이드.md](./부록A_라즈베리파이5-연동-인터페이스-가이드.md) ➡️ 나중에 실기기 GPIO 연결할 때 참고.
